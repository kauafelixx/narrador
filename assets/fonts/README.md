# Montserrat

Fonte variável local, pesos 100–900, utilizada pela interface sem requisições a serviços externos.

- Fonte oficial: https://github.com/google/fonts/tree/main/ofl/montserrat
- Arquivo: `Montserrat-Variable.ttf` (`Montserrat[wght].ttf` na origem).
- Licença: SIL Open Font License 1.1; cópia em `OFL.txt`.
